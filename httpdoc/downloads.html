Downloads

The toy, the bundle, the sources with the store they compile from, and four directories of guest images to put in /var/lib/cloonix/bulk.

Cloonix

cloonix-toy-100.tar.gz cloonix inside its own container. No root, nothing installed: extract, ./setup.sh nemo, ./nemocmd start. Get started uses this one.
cloonix-bundle-100.tar.gz the compiled run-time for a machine several people share. Installed once as root by sudo ./install_cloonfs, under /usr/libexec/cloonix.
cloonix-source-100.tar.gz the source tree: cloonix, the demos, the image builders of vm_create, the tests, the two books. The same tree as github.com/clownix/cloonix; ./doitall at its root builds the bundle, toy_targz/create_toy_targz.sh the toy.
cloonix-targz_store-100.tar.gz goes with the sources, and is needed before anything compiles: the open sources cloonix rebuilds, qemu, open vswitch, crun, passt and patchelf, each at the commit this version was made with, and the base root file-system. Extracted at the root of the source tree it is the targz_store directory, which ./doitall reads instead of the internet.

To compile, the two together:

wget https://clownix.net/downloads/cloonix-source-100.tar.gz
wget https://clownix.net/downloads/cloonix-targz_store-100.tar.gz
tar xf cloonix-source-100.tar.gz
cd cloonix-source-100
tar xf ../cloonix-targz_store-100.tar.gz
./doitall

The build runs inside a debian trixie machine made by build_tools/vmbuild/doitall.sh; the chapter on building of the documentation has the steps. To run cloonix and not compile it, the toy alone:

wget https://clownix.net/downloads/cloonix-toy-100.tar.gz
tar xf cloonix-toy-100.tar.gz

Guest images

A guest needs an image in /var/lib/cloonix/bulk, the same directory for the bundle and for the toy. The four directories below hold what vm_create/allbulk.sh of the source tree builds, from a local mirror of each distribution, without root.

A container image: .tar.gz

Copied into bulk as it is. The first add cnt on it extracts it once, into <image>_targz, for every network and every user of the machine.

cd /var/lib/cloonix/bulk
wget https://clownix.net/downloads/cnt_bulk/trixie.tar.gz
cloonix cli nemo add cnt c1 eth=1 trixie

The extracted tree is never modified and takes no --persistent. For an image to change, extract it under another name: mkdir mytrixie && tar xpf trixie.tar.gz -C mytrixie.

A machine image: .qcow2.gz

Gunzipped into bulk. A machine started on it writes to a disk of its own derived from the image, which stays as downloaded.

cd /var/lib/cloonix/bulk
wget https://clownix.net/downloads/kvm_bulk/trixie.qcow2.gz
gunzip trixie.qcow2.gz
cloonix cli nemo add kvm k1 ram=1000 cpu=2 eth=1 trixie.qcow2

The account needs /dev/kvm, /dev/vhost-net and /dev/net/tun: step 1.
